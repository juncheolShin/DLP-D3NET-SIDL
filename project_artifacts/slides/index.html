Motivation

Dirty lens restoration is not ordinary denoising

  • Smartphone lenses are exposed to dust, fingerprint, scratch, water, and mixed residue.
  • Contamination creates spatial artifacts and frequency-domain distortion at the same time.
  • SIDL provides real-world paired images for supervised dirty lens restoration.
SIDL task 512×512 paired patches 6 contamination types Easy / Medium / Hard difficulty

Why D3Net?

All-in-one restoration with degradation prompts

  • U-Net style encoder-decoder preserves multi-scale spatial detail.
  • Fourier branch extracts frequency-domain degradation cues.
  • CDDA creates degradation correction and strategy prompts.
  • DDB dynamically chooses restoration paths through DUs and ADBs.

Method Overview

Input dirty image → D3Net residual → restored image

Original D3Net architecture figure from Wang et al., arXiv:2502.19068. In this project, the predicted residual is added to the dirty input for final restoration.

Ablation & Discussion

Patch size creates a training trade-off

  • 128 crop lacks enough spatial context for lens contamination.
  • 256 crop balances context, random crop diversity, and batch dynamics.
  • 512 refinement changes the effective training distribution.
  • Batch size drops to 1, making optimization less stable.

Conclusion

Hard Dust / Mixed remains the main bottleneck

  • D3Net reached 23.82 dB / 0.8398 on the controlled 256 crop run.
  • Larger-patch refinement did not guarantee improvement.
  • Future work: pretrained models, TTA/self-ensemble, difficulty-aware sampling, and loss redesign.
