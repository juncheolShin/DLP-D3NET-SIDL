Motivation

Dirty lens restoration is not ordinary denoising

  • Smartphone lenses are exposed to dust, fingerprint, scratch, water, and mixed residue.
  • Contamination creates spatial artifacts and frequency-domain distortion at the same time.
  • SIDL provides real-world paired images for supervised dirty lens restoration.

Method Overview

D3Net: CDDA prompts + dynamic degradation decomposition

D3Net predicts a residual correction. Inference output is restored image = dirty input + predicted residual.

Dynamic Block

DUs select whether ADBs should process degradation-aware features

Decision Units conditionally activate Adaptive Decomposition Blocks to adapt the processing path to local and mixed contamination patterns.

Experimental Setup

Controlled scratch training on SIDL validation split

Train dataSIDL 512×512 patchified degraded-clean pairs
Train crop256×256 random crop from 512 patch
Validation512×512 center crop, PSNR / SSIM
ModelD3Net, 12 ADB blocks, residual output
OptimizationL1 loss, Adam, cosine LR, scratch training
HardwareSingle RTX 4090, limited class-project budget

This is an adaptation and ablation study, not a SIDL SOTA claim.

Conclusion

Hard Dust / Mixed remains the main bottleneck

Main takeaway

For dirty lens restoration, a larger patch is not automatically better. 256×256 crop training gave the best balance between context, augmentation diversity, and optimization stability.
