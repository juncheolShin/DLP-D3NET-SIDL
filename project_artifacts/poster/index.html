Motivation

  • Smartphone lenses are easily contaminated by dust, fingerprints, scratches, water drops, and mixed residue.
  • Dirty lens degradation creates both spatial artifacts and frequency-domain distortion.
  • The core question is whether a degradation-adaptive all-in-one model can handle SIDL restoration.

SIDL Dirty Lens Restoration Task

SIDL is a real-world paired dataset for restoring smartphone images captured through contaminated lenses. This project uses 512×512 patchified degraded-clean pairs and evaluates PSNR/SSIM by contamination type and difficulty.

512×512 center crop, PSNR / SSIM
Hardware
Single RTX 4090, class-project budget

D3Net Architecture

D3Net combines a reconstruction branch with a degradation decomposition branch. In this project, the network predicts a residual correction and the restored image is computed as input + residual.

Dynamic Degradation Decomposition

Decision Units conditionally activate Adaptive Decomposition Blocks, allowing degradation-aware processing for mixed and local contamination patterns.

Takeaways

  1. D3Net can be adapted to SIDL dirty lens restoration under limited compute.
  2. 256×256 crop training was the most stable setting.
  3. 512 refinement suggests patch-size-induced training distribution shift.
  4. Hard Dust/Mixed remains the main bottleneck.
